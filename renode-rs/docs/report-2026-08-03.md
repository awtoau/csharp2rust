## C#/Rust semantic long tail

Issue [#58](https://github.com/awtoau/awto-renode-rs/issues/58) is the canonical
measurement and classification; the executable census is
`scripts/semantic_differences_census.py`. Current full-tree figures include 2
actual destructors, 126 `Dispose` methods / 215 `using` operations, 143 `ref`
and 610 `out` parameters, and 29 genuinely mutable statics after separating
34,600 const-valued and 222 `static readonly` fields. Ordinary `ref`/`out`
methods now emit `&mut` faithfully; mutable-static access is explicitly
withheld instead of being silently converted to per-instance state. Detailed
deferred classifications and the complete static enumeration are in
`docs/issues/0-status-58.md`. The issue remains open: five rows apply to the
full corpus but are still deferred, so they do not meet the literal
handled-or-not-applicable acceptance condition yet.

## The two things blocking everything

**1. Nothing has ever executed.** The converter emits effectively none of the
infrastructure — `SystemBus` gives an *empty* `define_registers` from 200
members, `MappedMemory` 4 trivial getters from 74. 594 compiling modules with no
bus is 594 files.

Target: `tests/unit-tests/stm32f4-erase.robot :: Should Perform Mass Erase` —
3 server keywords, 5 monitor verbs, no CPU, no ELF. Renode's 265 Robot tests are
language-neutral and need no translation.

**2. Behaviour is barely translated.** ADC, DMA and the timers have register
maps and almost no behaviour. That is the work; the fact that trace replay
cannot check it afterwards is recorded, not waited on.

## Rules found wrong this week

Not incomplete — wrong:

- `<<` / `>>`, **255 sites**: C# masks the shift count (ECMA-334 §12.11); `1 << 32` is `1` in C#, a panic in Rust
- `Dictionary.Add`, **86 sites**: C# throws on a duplicate key; `insert` overwrites
- `OrderBy` → `{recv}`: a sort that does not sort
- `First` → `.unwrap()`: C# throws `InvalidOperationException`
- LINQ keyed by name only, so every overload took the first overload's template
- `String.Append` / `ToString` keyed on the *Rust* type: could never match, counted as coverage
- `Nullable.Value` / `HasValue` missing, 26 sites, emitting `x.value()` on `Option<T>`

## History

The ingest once ran over a hand-typed file list (the "cut"). It was removed on
2026-08-02 — `docs/decisions/remove-the-cut.md` — because it truncated 69% of
inheritance chains and left 114 of 126 interfaces unresolved. Both now 26% and
12. Not revisited.
